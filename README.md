# INCMTL Cab Co. – APK

1. Załóż darmowe konto na github.com i utwórz nowe, puste repozytorium.
2. Wgraj do niego całą zawartość tego folderu (razem z ukrytym folderem .github).
3. Wejdź w zakładkę Actions i poczekaj, aż zadanie "Build APK" zrobi się zielone (kilka minut).
   Jeśli się nie uruchomiło: Actions > Build APK > Run workflow.
4. Otwórz zakończone zadanie, na dole w sekcji Artifacts pobierz incmtl-cab-co-apk (to zip z app-debug.apk).
5. Przenieś APK na telefon i zainstaluj. Android zapyta o zgodę na instalację z nieznanych źródeł.

Grę edytujesz w www/index.html. Po każdej zmianie wgraj plik do repozytorium, a APK zbuduje się od nowa.
